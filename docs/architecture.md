## Agents and access boundaries

| Agent | Role | MCP tools | Other tools | Denied |
| --- | --- | --- | --- | --- |
| `dispatcher` | Entry point, reports, SolaX stats and (optional) mode changes | `solax-cloud__*` | memory, read/write own workspace, `sessions_spawn`/`yield`/`send` | `netatmo-weather__*`, `rce-prices__*`, exec, web, browser, messaging, automation |
| `weather-cast` | Station readings, forecast, PV outlook | `netatmo-weather__*` | memory, own workspace, `sessions_send` | `solax-cloud__*`, `rce-prices__*`, `sessions_spawn`, `subagents`, + global denies |
| `trader` | RCE price analysis and timing advice | `rce-prices__*` | memory, own workspace, `sessions_send` (asks weather-cast) | `solax-cloud__*`, `netatmo-weather__*`, `sessions_spawn`, `subagents`, + global denies |

Layers that enforce the boundaries (all generated by `scripts/render_config.py`):

1. **Global tool policy**: `tools.profile: minimal` plus an explicit `alsoAllow`
   list; exec, web, browser, messaging, automation and media groups are denied;
   file tools are limited to the agent's own workspace.
2. **Per-agent deny lists**: each agent denies the other agents' MCP servers with
   `server__*` globs, so an agent cannot reach another agent's data source even if
   prompted to.
3. **Agent-to-agent allowlist**: `tools.agentToAgent.allow` contains only the
   three agents; only the dispatcher may spawn sub-agents (`subagents.allowAgents`).
4. **MCP server side**: `set_battery_self_use_mode` is removed from the SolaX
   server unless `SOLAX_ALLOW_CONTROL=true`, and OpenClaw's `toolFilter` hides it
   too. The tool is annotated `destructiveHint`, so OpenClaw also treats it as an
   approval-worthy action. Read tools carry `readOnlyHint`.
5. **Scheduled jobs** are created with a `--tools` cap that excludes battery control.
6. **Network**: MCP servers have no published ports and require a bearer token
   (`MCP_INTERNAL_TOKEN`); Gateway and Grafana publish on `127.0.0.1` only.

## Agent-to-agent (A2A)

Two complementary mechanisms:

- **Inside the Gateway**: the dispatcher delegates with `sessions_spawn` and
  collects results with `sessions_yield`; the trader consults weather-cast with
  `sessions_send`. In Discord (one bot per agent) handoffs are also visible as
  @mentions in the team channel.
- **Standard A2A 1.0 protocol** (`channels.a2a`): the Gateway publishes an Agent
  Card at `/.well-known/agent-card.json` with one skill per agent and accepts
  authenticated JSON-RPC `SendMessage`/`GetTask` at `/a2a/v1`. External agents
  (or `scripts/a2a_client.py`) can hand a task to the team; the task is routed to
  the dispatcher, which delegates internally.

## Persistent memory

OpenClaw memory is plain Markdown in each agent workspace, bind-mounted from
`.local/workspaces/<agent>` so it survives container restarts and new sessions:

- `MEMORY.md` – durable facts and preferences ("запам'ятай, мінімальний SOC 20%"),
  loaded at the start of every session.
- `memory/energy-log.md` – the dispatcher's evening/morning SolaX snapshots. The
  morning report computes overnight consumption and battery change from the
  previous evening's snapshot, i.e. it depends on memory written in a previous run.
- `memory/YYYY-MM-DD.md` – daily notes (weather events, daily price summaries),
  searchable with `memory_search`.

`render_config.py render` refreshes instruction files (`AGENTS.md`, `SOUL.md`,
`IDENTITY.md`, `TOOLS.md`) from `agents/` but never overwrites `MEMORY.md`,
`USER.md` or `memory/`.

## Reports

| Job | Default schedule | Content |
| --- | --- | --- |
| Morning | `0 7 * * *` Europe/Warsaw | Battery after the night, overnight consumption, today's weather and PV outlook, today's prices, one recommendation |
| Evening | `30 21 * * *` | Today's production, grid import/export, daily consumption, battery before the night, tomorrow's weather and prices |

Jobs run in isolated sessions and announce the final reply to Discord and/or
WhatsApp (`scripts/setup_automations.sh`).

## Data sources

| Source | Access | Notes |
| --- | --- | --- |
| SolaX Developer Platform (`openapi-eu.solaxcloud.com`) | OAuth2 client credentials | Real-time only (no history); daily figures come from `today*` counters and stored snapshots. Upstream rate limit 100 calls/min. |
| Netatmo (`api.netatmo.com`) | OAuth2, `read_station` | Refresh tokens rotate; the current one is kept in the `weather-state` volume. |
| Open-Meteo | none | Forecast, sunshine, irradiation for the house location. |
| godzinowe.pl API | none (free for private use) | PSE RCE hourly prices; responses cached per day; 429 falls back to cache. |
