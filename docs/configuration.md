# Configuration reference (environment variables)

All configuration lives in `.env` in the repository root (git-ignored, mode
`0600`). Start from the template:

```bash
python3 scripts/render_config.py init     # copies .env.example -> .env and generates internal secrets
```

After any change: `python3 scripts/render_config.py render` and
`docker compose up -d` (re-creates only the containers whose settings changed).

Legend:

- **Secret** — a credential. Never commit, paste into chats or issues, or put in screenshots.
- **Private** — not a credential, but identifies you (IDs, phone numbers, location). Keep in `.env`.
- **Req.** — ✅ required, ➖ optional, 🔁 required only when the feature is enabled.
- **Used by** — the component that reads the value. Docker passes each value only
  to the container that needs it (see `docker-compose.yml`).

## Internal secrets (generated by `init`)

| Variable | Req. | Secret | Used by | Description |
| --- | --- | --- | --- | --- |
| `OPENCLAW_GATEWAY_TOKEN` | ✅ | Secret | openclaw | Token for the Control UI (http://127.0.0.1:18789), the CLI inside the container and Gateway RPC. |
| `MCP_INTERNAL_TOKEN` | ✅ | Secret | openclaw, solax-mcp, weather-mcp, prices-mcp | Shared bearer token between OpenClaw and the three MCP servers. Becomes `MCP_AUTH_TOKEN` inside the MCP containers. |
| `A2A_CLIENT_TOKEN` | ✅ | Secret | openclaw, `scripts/a2a_client.py` | Bearer token of the `homework-client` A2A peer for `/a2a/v1`. |
| `GRAFANA_ADMIN_PASSWORD` | ✅ | Secret | lgtm | Password of the Grafana `admin` user (http://127.0.0.1:3000). |

`init` fills only empty values, so it never replaces a token you already use. To
rotate one, clear it in `.env`, run `init` and `render`, then `docker compose up -d`.

## Home

| Variable | Req. | Secret | Used by | Description |
| --- | --- | --- | --- | --- |
| `HOME_TZ` | ➖ | — | all | IANA time zone for reports, prices and forecasts. Default `Europe/Warsaw`. |
| `HOME_LAT` | ➖ | Private | weather-mcp | Forecast latitude. If empty (with `HOME_LON`), the Netatmo station location is used. Two or three decimals are enough. |
| `HOME_LON` | ➖ | Private | weather-mcp | Forecast longitude. |
| `PV_KWP` | ➖ | — | weather-mcp | Installed PV peak power in kWp. Enables the rough daily `pv_estimate_kwh`. |
| `MORNING_REPORT_CRON` | ➖ | — | setup_automations.sh | Cron expression in `HOME_TZ`. Default `"0 7 * * *"`. Keep the quotes. |
| `EVENING_REPORT_CRON` | ➖ | — | setup_automations.sh | Default `"30 21 * * *"`. Keep the quotes. |

Changing a cron value affects only newly created jobs. Delete the old job in the
Control UI (Automations) and run `scripts/setup_automations.sh` again.

## SolaX Cloud (dispatcher only)

Create an application at https://developer.solaxcloud.com (client credentials).

| Variable | Req. | Secret | Used by | Description |
| --- | --- | --- | --- | --- |
| `SOLAX_CLIENT_ID` | ✅ | Secret | solax-mcp | OAuth client ID of the SolaX Developer Platform app. |
| `SOLAX_CLIENT_SECRET` | ✅ | Secret | solax-mcp | OAuth client secret. |
| `SOLAX_DEVICE_SN` | ✅ | Private | solax-mcp | Inverter serial number. |
| `SOLAX_ALLOW_CONTROL` | ➖ | — | solax-mcp, render_config | `true` exposes `set_battery_self_use_mode` (removed on both the MCP server and the OpenClaw side otherwise). The dispatcher still requires your explicit confirmation, and scheduled jobs never get it. Default `false`. |

## Netatmo (weather-cast only)

Create an app at https://dev.netatmo.com/apps with redirect URI
`http://localhost:8765/callback`, then run `python3 scripts/netatmo_auth.py`.

| Variable | Req. | Secret | Used by | Description |
| --- | --- | --- | --- | --- |
| `NETATMO_CLIENT_ID` | ✅ | Secret | weather-mcp, netatmo_auth.py | Netatmo app client ID. |
| `NETATMO_CLIENT_SECRET` | ✅ | Secret | weather-mcp, netatmo_auth.py | Netatmo app client secret. |
| `NETATMO_REFRESH_TOKEN` | ✅ | Secret | weather-mcp | Bootstrap refresh token (scope `read_station`), written by `netatmo_auth.py`. Netatmo rotates it; the current token is kept in the `weather-state` volume, so this value is only used on first start or after that volume is removed. |
| `NETATMO_DEVICE_ID` | ➖ | Private | weather-mcp | MAC address of the base station, if the account has several. |

## Set by Docker Compose (do not put in `.env`)

Listed for running the MCP servers outside Docker (stdio or HTTP).

| Variable | Default | Description |
| --- | --- | --- |
| `MCP_TRANSPORT` | `stdio` (Docker: `http`) | `stdio` or `http` (streamable HTTP). |
| `MCP_AUTH_TOKEN` | — (Secret) | Required bearer token in HTTP mode; Docker sets it from `MCP_INTERNAL_TOKEN`. |
| `MCP_ALLOW_NO_AUTH` | unset | `1` allows HTTP mode without a token. Local experiments only. |
| `MCP_HOST` / `MCP_PORT` | `0.0.0.0` / `8000` | HTTP listen address. |
| `HOME_MCP_STATE_DIR` | `~/.local/state/home-mcp` (Docker: `/data`) | Rotated Netatmo token and price cache. |
| `PRICES_API_URL` | `https://godzinowe.pl/api.php` | Prices API base URL (tests point it at a local fake). |
| `LOG_LEVEL` | `INFO` | MCP server log level. |
| `OPENCLAW_CONFIG_PATH`, `OPENCLAW_STATE_DIR`, `OPENCLAW_HOME`, `HOME`, `TZ` | see compose | Paths and time zone inside the OpenClaw container. |
| `A2A_BASE_URL` | `http://127.0.0.1:18789` | Gateway URL for `scripts/a2a_client.py`. |

## Where secrets end up

| Secret | Stored in |
| --- | --- |
| Everything above marked *Secret* | `.env` only. The rendered config contains `${VAR}` / `{source: env}` references, not values. |
| Rotated Netatmo refresh/access token | `weather-state` Docker volume (`/data/netatmo-token.json`, mode 0600). |
| Model login (if you used `models auth login`), WhatsApp linked session, installed plugins | `openclaw-state` Docker volume. |
| Grafana data | `lgtm-data` Docker volume. |

Run `python3 scripts/check_secrets.py` before committing. It fails if any value
of a secret or private variable from `.env` appears in a file git would commit.
