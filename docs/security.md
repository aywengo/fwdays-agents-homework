# Безпека та секрети

- Усі облікові дані зберігаються в `.env` (права 0600, у `.gitignore`).
  `render_config.py` записує в конфіг OpenClaw лише посилання на змінні
  середовища (`${VAR}` / `{source: env}`); приватні ID (Discord, номери телефонів)
  потрапляють лише в ігнорований каталог `.local/`.
- Кожен контейнер отримує тільки ті змінні, які йому потрібні (див.
  `docker-compose.yml`): облікові дані SolaX доходять лише до `solax-mcp`,
  Netatmo — лише до `weather-mcp`.
- Ротовані токени Netatmo та кеш цін зберігаються в томах Docker, а не в репозиторії.
- Gateway (18789) і Grafana (3000) слухають лише на `127.0.0.1`. MCP-сервери не
  мають портів на хості та вимагають bearer-токен. Для віддаленого доступу
  використовуйте Tailscale або SSH-тунелі.
- Discord і WhatsApp працюють за allowlist: з агентами може спілкуватися лише
  власник (і боти команди — для передачі задач); захист від циклів між ботами увімкнено.
- A2A-партнери автентифікуються власним bearer-токеном; slash-команди з A2A
  OpenClaw відхиляє; A2A-задачі виконуються зі звичайною політикою інструментів
  dispatcher-а.
- Керування батареєю вимкнене за замовчуванням, потребує явного підтвердження
  користувача в чаті, ніколи не доступне запланованим завданням і позначене як
  деструктивне.
- Перед комітом запускайте `python3 scripts/check_secrets.py`.
- Повний перелік змінних і де зберігається кожен секрет: [configuration.md](configuration.md).
